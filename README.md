# Captain Coaster — exploration de refonte

Document de travail. Trois directions de refonte du site captaincoaster.com,
plus une reproduction fonctionnelle du site actuel qui sert de point de
comparaison.

**Ouvrir l'index :** la page d'accueil de ce site.

- `index.html` — l'index des trois directions (le document a lire)
- `redesign/` — les 15 ecrans, la recherche et l'argumentaire
- `clone.html`, `en/` — la reproduction du site actuel
- `data/` — le jeu de donnees extrait du site public

Les photographies sont des substituts libres de droits (Unsplash) ; les credits
figurent dans `redesign/assets/img/CREDITS.md`. Aucune page ne contacte les
serveurs de Captain Coaster.
